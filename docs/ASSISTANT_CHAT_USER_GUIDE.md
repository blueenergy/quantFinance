# 智能助手（对话）使用说明

本文说明：**用户在已登录前提下**，通过前端 **ChatPanel / 智能助手** 发起对话时，系统能提供哪些能力，以及哪些问题会 **自动附带本站后台数据**（便于大模型基于事实作答）。

适用范围取决于前端配置：当 **`VITE_ASSISTANT_STREAM_BACKEND=hermes`** 时，对话由 **quant-api** 的 `/api/assistant/chat/stream`（Hermes BFF）转发至 **Hermes** 网关；下文所述「自动注入数据」均在该路径下由 **BFF 在调用 Hermes 之前**完成。

---

## 1. 通用对话（任意话题）

未命中下文「关键词触发」时，助手主要表现为 **大模型的一般问答**：解读概念、梳理逻辑、写作辅助等。此类回复 **不保证** 附带本站数据库中的行情或个股专有数据，请勿将其等同于交易所实时行情终端。

---

## 2. 自动附带「连板天梯」数据的问法

当用户消息中出现若干 **与涨停梯队相关的措辞** 时，后台会将当日（或最近交易日）**连板天梯 JSON 摘要**写入对话上下文，模型应基于该数据归纳回答。

**示例问法（不必完全一致）：**

- 今天连板天梯怎么样？
- 看一下涨停梯队、几连板分布
- 今日连板股高度如何？

**数据来源：** 与接口 `GET /api/hermes-tools/ladder/daily`（及站内天梯逻辑）同源。

---

## 3. 自动附带「自选股深度分析历史」的问法

当用户消息中出现 **与历史分析报告相关的措辞** 时，后台会读取 **当前登录用户** 在 `analysis_history` 中的记录（与 **`GET /api/analysis-history`** 同源），按时间倒序取近期若干条，并摘要注入上下文。

**示例问法：**

- 我之前做过哪些自选股深度分析？
- 看一下我的深度分析历史 / 分析历史记录
- 帮我总结一下最近的深度分析结论

若消息中包含 **A 股代码**（如 `600519` 或 `600519.SH`），通常会 **按该标的过滤** 历史记录。

**数据来源：** `GET /api/analysis-history`（需登录；仅本人数据）。

---

## 4. 同时使用多个数据源

若一句话 **同时命中** 连板类关键词与分析历史类关键词，两段内容会以分隔符合并进 **同一条系统提示**，再送给模型统一理解。

---

## 5. 限制与预期

- **权限：** 分析历史仅包含 **当前账号** 下产生的记录；未登录或无效会话无法使用此类注入。
- **长度：** 单次注入有字符上限（防止超出模型上下文）；超长时会截断并标注截断说明。
- **实时性：** 「天梯」「分析历史」均来自 **本站已落库数据**，不是交易所逐笔推送。
- **触发方式：** 当前为 **关键词（短语）匹配**，表述与此不完全一致时可能不会触发注入；可后续在产品迭代中扩展触发词（见开发配置）。

---

## 6. 开发与运维（可选阅读）

| 说明 | 位置 |
|------|------|
| 连板关键词与注入开关 | `quantFinance/routers/assistant_bff.py`（`_LADDER_TRIGGERS`、`HERMES_LADDER_INJECT_*`） |
| 分析历史关键词与注入开关 | 同上（`_ANALYSIS_HISTORY_TRIGGERS`、`HERMES_ANALYSIS_HISTORY_*`） |
| 环境变量示例 | `quantFinance/.env.template` |

扩展助手能力时，建议沿用同一模式：**在 BFF 层按需查询内部 API 或服务**，再注入 `messages`，而非依赖 Hermes 容器内临时执行脚本。
