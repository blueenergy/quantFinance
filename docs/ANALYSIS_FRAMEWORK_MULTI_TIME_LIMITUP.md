# A股跨时间维度涨停分析与根因诊断框架

> **版本**：v1.0  
> **目标**：从单日的情绪波动分析，升级为多时间维度的行业动能与事件驱动深度分析。

---

## 1. 多维时间分析矩阵 (Multi-Temporal Matrix)

传统的分析仅关注当日涨停，本框架引入 **D (日) / W (周) / M (月)** 三级梯度，识别资金在不同周期下的行为：

| 维度 | 统计核心 | 交易含义 |
| :--- | :--- | :--- |
| **日度 (Daily)** | 首板家数、连板高度、领涨行业 | **情绪风向标**：捕捉当日最热的题材。 |
| **周度 (Weekly)** | 行业累计涨停频次、行业覆盖率 | **动能确认**：识别哪些题材具备持续性，而非“一日游”。 |
| **月度 (Monthly)** | 核心行业爆发频率、涨停逻辑一致性 | **主线识别**：沉淀出真正的机构或大资金认可的月度/季度主线。 |

### 关键量化信号
- **环比突破 (Breakout)**：行业当日/本周涨停数 > 过去 N 周均值 300% 以上。
- **动能持续 (Momentum)**：行业在月度统计中，涨停个数呈现斜率向上的分布。
- **衰退预警 (Decay)**：行业在高位出现涨停数骤减，且无新的领涨股票接力。

## 2. “涨停-指数”共振分析 (Market Resonance)

将涨停板（情绪先锋）与行业指数/ETF（中军共识）结合，规避虚假突破。

### 核心共振模型
1. **强共识 (High Resonance)**：涨停潮爆发 + 行业 ETF 放量突破。
    *   *逻辑*：游资打高度，机构扫货中军。这是最高级别的参与信号。
2. **纯情绪 (Pure Sentiment)**：涨停潮爆发 + 行业 ETF 缩量或滞涨。
    *   *逻辑*：边缘股/微盘股抱团，缺乏基本面支撑。极易发生“A字杀”。
3. **潜伏期 (Latency)**：涨停稀少 + 行业 ETF 持续小步走高。
    *   *逻辑*：典型的机构推升行情。适合作为左侧买入点。

## 3. AI 根因分析与归因 (AI Root-Cause Analysis)

利用 LLM 将“结构化数据”翻译成“深度洞察”。

### 3.1 归因维度
当检测到**环比突破**时，AI 将自动扫描并匹配以下归因因子：
- **政策驱动**：近期的国常会、行业规划、政府工作报告。
- **宏观周期**：降息、大宗商品价格波动（如电煤价格对电力板块的影响）。
- **重大事件**：如 AI 大会、低空经济试点城市发布、重组重大利好。
- **季节性因素**：如避暑用电高峰、双十一消费、财报季业绩反转。

### 3.2 诊断逻辑链
AI 的输出应遵循“**现状 -> 归因 -> 信号 -> 建议**”的链条。
> *示例输出*：“电力板块本周涨停频次异常激增（环比+400%），核心归因于《电力体制改革》政策超预期及煤价持续下行。当前形成‘强共识’共振，判定为‘环比突破’。建议关注行业龙头及具备业绩弹性的首板股票。”

## 4. 技术落地架构

### 4.1 数据流
1. **Collector**：通过 AkShare 定时抓取东财板块行情与 ETF 数据。
2. **Aggregator**：每日收盘后计算 `weekly/monthly_limitup_industry_stats`。
3. **Engine**：对比 D/W/M 均值，触发异动逻辑，组装 Context 提交给 LLM。
4. **Knowledge**：AI 分析结果存入 `analysis_history`。

### 4.2 核心存储 (MongoDB)
- `daily_limit_up_industry_stats` (存量更新)
- `weekly_limitup_industry_stats` (算好存好)
- `market_industry_quotes_daily` (行情基准)
