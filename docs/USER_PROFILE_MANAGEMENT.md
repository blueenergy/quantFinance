# 用户配置管理模块设计文档

## 概述

本文档详细描述了重新设计的用户配置管理系统，旨在提供更专业、更安全、更易用的用户配置管理功能。

## 设计目标

1. **统一的配置中心**：将所有用户相关配置集中管理
2. **安全的邮箱验证**：注册时必须验证邮箱
3. **清晰的界面结构**：使用标签页组织不同类型的配置
4. **安全的API密钥管理**：不在前端显示已保存的密钥

## 功能模块

### 1. 个人资料管理

- 用户名（不可修改）
- 邮箱地址（支持修改，需验证）
- 全名
- 邮箱验证状态

### 2. 安全设置

- 密码修改
- 双因素认证（预留接口）
- 登录历史（预留接口）

### 3. AI服务配置

- LLM提供商选择（OpenAI、DeepSeek、自定义）
- API密钥配置
- API基础URL配置
- 模型名称配置
- 配置测试功能

### 4. 证券账户管理

- 券商选择
- 账户ID管理
- 交易密码管理
- 账户状态管理

## API端点

### 用户配置相关端点

- `GET /api/user/profile` - 获取用户完整资料
- `PUT /api/user/profile` - 更新用户资料
- `PUT /api/user/email` - 更新用户邮箱并发送验证邮件
- `POST /api/user/resend-verification` - 重新发送验证邮件
- `GET /api/user/verify-email` - 验证邮箱地址
- `POST /api/user/change-password` - 修改用户密码
- `PUT /api/user/two-factor` - 更新双因素认证设置
- `PUT /api/user/llm-config` - 更新LLM配置
- `POST /api/user/llm/test` - 测试LLM配置

### 证券账户相关端点

- `GET /api/user/accounts` - 获取用户证券账户列表
- `POST /api/user/securities_account` - 创建证券账户
- `PUT /api/user/securities_account/{account_id}` - 更新证券账户
- `DELETE /api/user/securities_account/{account_id}` - 删除证券账户

## 邮箱验证流程

1. 用户注册时，账户默认为非激活状态
2. 系统发送验证邮件到用户邮箱
3. 用户点击验证链接激活账户
4. 验证成功后，用户可以正常登录

## 安全措施

1. **邮箱验证**：注册时必须验证邮箱
2. **API密钥安全**：前端不显示已保存的API密钥
3. **密码安全**：密码使用bcrypt加密存储
4. **会话管理**：使用JWT进行认证管理

## 前端路由

在App.vue中添加了新的"用户配置"标签页，用户可以方便地访问所有配置功能。

## 使用说明

### 用户注册
1. 用户填写注册信息
2. 系统发送验证邮件
3. 用户点击验证链接
4. 账户激活，可以登录

### 配置管理
1. 登录后点击顶部用户配置按钮
2. 或在主界面选择"用户配置"标签页
3. 在不同标签页中管理各类配置

## 部署说明

### 环境变量配置

需要在`.env`文件中配置SMTP服务信息：

```bash
# SMTP邮件配置
SMTP_SERVER=smtp.gmail.com
SMTP_PORT=587
SMTP_USERNAME=your_email@gmail.com
SMTP_PASSWORD=your_app_password
SMTP_FROM_EMAIL=no-reply@yourdomain.com
```

### 数据库迁移

新用户注册将自动使用新的验证流程，现有用户数据保持不变。
