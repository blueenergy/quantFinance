# 用户自选股功能测试指南

## 📈 功能概述

现在自选股已经与用户账户绑定，不同用户登录后可以看到各自独立的自选股列表。

## 🔄 功能特性

### ✅ 已实现的功能

1. **用户认证集成**
   - 登录用户的自选股保存在服务器端
   - 未登录用户的自选股保存在本地浏览器
   - 登录时自动迁移本地自选股到服务器

2. **个性化自选股管理**
   - 每个用户有独立的自选股列表
   - 支持添加、删除、批量更新自选股
   - 实时同步到服务器端数据库

3. **智能数据迁移**
   - 用户登录时自动检测本地自选股
   - 自动迁移本地数据到服务器
   - 迁移成功后清理本地数据

4. **状态提示**
   - 显示用户登录状态和数据存储位置
   - 迁移完成后显示成功提示
   - 友好的用户体验提示

## 🧪 测试流程

### 1. 未登录状态测试
```
1. 打开 http://localhost:5173
2. 不登录，直接在自选股页面添加股票（如000001）
3. 观察页面显示"未登录状态下的自选股仅保存在本地浏览器中"
4. 刷新页面，确认股票仍在列表中（localStorage保存）
```

### 2. 用户注册和登录测试
```
1. 点击登录按钮，然后选择注册
2. 填写用户信息：
   - 用户名：testuser001
   - 邮箱：testuser001@example.com  
   - 密码：password123
   - 全名：Test User 001
3. 注册成功后登录
4. 观察自选股页面状态变化
```

### 3. 数据迁移测试
```
1. 在未登录状态下添加几只股票到自选股
2. 然后登录用户账户
3. 观察是否显示"本地自选股已成功迁移到服务器！"
4. 确认所有本地股票都出现在用户自选股中
```

### 4. 多用户隔离测试
```
1. 用用户A登录，添加股票：000001, 000002
2. 注销用户A
3. 用用户B登录，添加股票：300347, 600000
4. 分别用两个用户登录，确认看到不同的自选股列表
```

### 5. API测试
使用提供的测试脚本：
```bash
python tests/test_user_watchlist.py
```

## 🔧 技术实现

### 后端API端点

1. **GET /api/user/watchlist** - 获取用户自选股列表
2. **POST /api/user/watchlist/add** - 添加股票到自选股
3. **DELETE /api/user/watchlist/remove** - 从自选股移除股票
4. **PUT /api/user/watchlist** - 批量更新自选股
5. **GET /api/user/watchlist-stocks** - 获取用户自选股详细信息

### 前端组件增强

1. **WatchListData.vue**
   - 集成用户认证状态检测
   - 自动数据迁移逻辑
   - 服务器端/本地端数据管理切换

2. **watchlist.js服务**
   - 统一的自选股API调用接口
   - 本地数据迁移功能
   - 认证状态检测

### 数据库设计

MongoDB集合：`user_watchlists`
```javascript
{
  _id: ObjectId,
  user_id: String,      // 用户ID
  symbols: [String],    // 股票代码数组
  updated_at: Date      // 更新时间
}
```
